# Neon Dracula for Obsidian

A CSS snippet that gives Obsidian a neon cyberpunk aesthetic based on the Dracula color palette.

## Features

- Neon orange headers with glow and black outline for readability
- Neon green inline code with glow
- Purple glowing tables with 3D styling
- Purple bordered code blocks (glow in reading mode)
- Cyan comments in code blocks
- Styled blockquotes, tags, and list bullets

## Installation

### Quick Install

```bash
curl -o ~/.obsidian/snippets/neon-dracula.css \
  https://raw.githubusercontent.com/YOUR_USERNAME/obsidian-neon-dracula/main/neon-dracula.css
```

### Manual Install

1. Copy `neon-dracula.css` to your vault's `.obsidian/snippets/` folder
2. In Obsidian: Settings → Appearance → CSS Snippets
3. Click the reload button and enable "neon-dracula"

### Recommended Base Theme

This snippet is designed to work with the **Dracula** community theme.
